# QMI8658 IMU传感器示例

## 功能说明

本示例演示如何使用QMI8658六轴IMU传感器（加速度计+陀螺仪），实时采集并显示运动数据。

### 主要功能
- ✅ 实时显示三轴加速度数据（单位：g）
- ✅ 实时显示三轴角速度数据（单位：dps）
- ✅ 实时显示温度数据（单位：°C）
- ✅ 自动检测QMI8658A/C型号
- ✅ 支持手动和自动校准
- ✅ 显示校准状态

## 硬件需求

- AC6321A开发板
- QMI8658模块（I2C接口）
- OLED显示屏（128×64，SSD1306驱动）

## 引脚连接

| QMI8658引脚 | 开发板引脚 | 说明 |
|-----------|-----------|------|
| VCC       | 3.3V      | 电源 |
| GND       | GND       | 地   |
| SDA       | PA1       | I2C数据 |
| SCL       | PA0       | I2C时钟 |
| INT1      | PB5       | 中断1（可选） |
| INT2      | PB6       | 中断2（可选） |

**注意**：QMI8658的I2C地址为 `0x6A`（SA0引脚接地）

## 使用方法

### 1. 选择显示方式（可选）

本示例支持两种OLED显示方式，在 `qmi8658_example.c` 文件开头配置：

```c
// 0 = 使用原生OLED驱动（速度快，资源少）
// 1 = 使用u8g2图形库（功能丰富，支持动画）
#define USE_U8G2_DISPLAY    0
```

**原生OLED驱动**：
- ✅ 速度快，资源占用少
- ✅ 直接调用 `OLED_ShowString()` 等函数
- ❌ 功能相对简单

**u8g2图形库**：
- ✅ 丰富的字体和图形功能
- ✅ 支持圆形、进度条、动画等
- ❌ 资源占用较多
- ⚠️ **注意**：使用u8g2时，每帧需要清除缓冲区并完整重绘，否则会出现残影

**注意**：此宏只在当前示例中生效，不影响其他示例。

### 2. 启用示例

编辑 `board/example_config.h`：

```c
#define ENABLE_EXAMPLE_QMI8658          1  // 启用
#define ENABLE_EXAMPLE_U8G2_DASHBOARD   0  // 关闭其他示例
```

### 3. 编译烧录

```bash
make clean
make
# 使用杰理下载工具烧录
```

### 4. 操作说明

#### 显示布局

```
┌────────────────────────────────────────┐
│ QMI8658C              ■               │  ← 标题 + 校准指示器
├────────────────────────────────────────┤  ← 分隔线
│ AX:+0.12      GX:+1.23                │
│ AY:-0.45      GY:-2.34                │
│ AZ:+9.87      GZ:+0.12                │
│ T:25.6                                 │  ← 温度（左下角）
└────────────────────────────────────────┘
```

**设计特点**：
- ✅ **无残影**：每帧清除缓冲区并完整重绘
- ✅ **三字体**：大(标题) / 中(数据) / 小(温度)
- ✅ **图形元素**：校准状态用方块指示器
- ✅ **分隔线**：清晰区分标题和数据区
- ✅ **左右分栏**：加速度/角速度对称布局

## 按键功能

- **KEY3长按**：手动校准传感器
  - 校准过程中显示 "Calibrating"
  - 先校准陀螺仪，再校准加速度计
  - 校准完成后显示 "Done!"

### 自动校准

- 如果传感器未校准，每60秒会自动执行一次校准
- 校准过程中会暂停数据显示
- 校准完成后自动恢复显示

## 技术细节

### 数据格式

- **加速度**：原始数据除以8192得到g值
- **角速度**：原始数据除以16得到dps值
- **温度**：`(raw_temp / 256) + 25.0` 得到°C值

### 刷新频率

- 数据显示刷新率：约1000Hz（`os_time_dly(1)`）
- 实际刷新受OLED刷新速度限制

### 校准原理

1. **陀螺仪校准**：静止状态下采集1000个样本，计算零偏
2. **加速度计校准**：假设静止时Z轴为1g，X/Y轴为0g，计算偏差

## 注意事项

- ⚠️ 校准时必须保持传感器静止
- ⚠️ 确保I2C通信正常（可运行 `i2c_bus_scan()` 检查）
- ⚠️ QMI8658供电电压为3.3V，不要接5V
- ⚠️ I2C总线需要上拉电阻（通常模块已集成）

## 常见问题

### Q1: OLED不显示
**A**: 检查I2C连接，运行 `i2c_bus_scan()` 确认能检测到地址0x3C（OLED）和0x6A（QMI8658）

### Q2: 传感器初始化失败
**A**: 
1. 检查QMI8658供电是否正常
2. 确认I2C地址是否正确（SA0引脚接地时为0x6A）
3. 查看串口打印的错误信息

### Q3: 数据不准确
**A**: 执行校准操作（KEY3长按），确保校准时传感器静止

### Q4: 数据跳变大
**A**: 
1. 检查电源是否稳定
2. 确认I2C连线是否牢固
3. 尝试降低刷新频率
