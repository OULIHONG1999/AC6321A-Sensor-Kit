# 陀螺仪控制小球示例（平衡球游戏）

## 📖 项目简介

基于QMI8658加速度计传感器的平衡球游戏示例，通过倾斜设备控制屏幕上小球的滚动。

**核心特性**：
- ✅ **真实物理仿真**：使用加速度计重力分量模拟球在斜面上滚动
- ✅ **惯性效果**：回平后小球因惯性继续滑动
- ✅ **弹性碰撞**：边界反弹效果自然
- ✅ **实时数据显示**：标题栏显示X/Y轴加速度值（g单位）
- ✅ **可调参数**：灵敏度、摩擦力、小球半径可实时调整

## 🎮 功能特性

### 物理模型

采用真实的平衡球物理模型：

```
倾斜设备 → 重力产生分量 → 小球获得加速度 → 持续滚动
保持倾斜 → 加速度持续 → 速度不断增加 → 越滚越快
回到水平 → 加速度为0 → 摩擦力减速 → 慢慢停下
```

**物理公式**：
```c
// 1. 读取加速度计RAW值并转换为g
acc_x_g = sensor_data.acc_x / 8192.0f;  // QMI8658: ±4g量程, 8192 LSB/g

// 2. 低通滤波平滑数据
filtered_acc_x = 0.5 * acc_x_g + 0.5 * filtered_acc_x;

// 3. 计算加速度（g值 × 灵敏度）
ax = filtered_acc_x * sensitivity;

// 4. 速度积分
vx += ax * DT;

// 5. 应用摩擦力
vx *= (1.0 - friction);

// 6. 位置更新
x += vx * DT;
```

## ⚙️ 参数说明

### 灵敏度 (Sensitivity)
- **范围**：20 ~ 200
- **默认值**：80
- **步进**：±10
- **作用**：将加速度(g)转换为像素加速度
- **效果**：
  - S=20：轻微倾斜，缓慢滚动
  - S=80：标准配置，适中响应
  - S=150：快速响应，适合演示

### 摩擦力 (Friction)
- **范围**：0.05 ~ 0.50
- **默认值**：0.10
- **步进**：±0.05
- **作用**：模拟滚动阻力，控制减速快慢
- **效果**：
  - F=0.05：低摩擦，像冰面，滑很远
  - F=0.10：标准配置，自然减速
  - F=0.30：高摩擦，像地毯，很快停下

### 小球半径 (Radius)
- **范围**：2 ~ 6 像素
- **默认值**：3
- **步进**：±1
- **作用**：小球显示大小

## 🔧 技术实现

### QMI8658传感器配置

```c
// 硬件配置（qmi8658a.c）
加速度计量程：±4g
转换比例：8192 LSB/g
采样率：512Hz
低通滤波：50Hz

// 数据范围
RAW值：    -32768 ~ +32767 (int16_t)
g值：      -4.0g ~ +4.0g
```

### 数据转换流程

```c
// 1. RAW值 → g值
float acc_x_g = sensor_data.acc_x / 8192.0f;

// 2. 校准（驱动层自动完成）
// 水平放置时：Z轴=1g被减去，X/Y轴≈0

// 3. 倾斜时的重力分量
// 倾斜θ角度：acc_x = sin(θ) × 1g
// 例如：倾斜30° → acc_x ≈ 0.5g
```

### 物理仿真

```c
// 时间步长固定为 20ms (50Hz)
#define DT  0.02f

// 1. 读取并转换加速度计数据
float acc_x_g = sensor_data.acc_x / 8192.0f;
float acc_y_g = sensor_data.acc_y / 8192.0f;

// 2. 低通滤波（alpha=0.5）
filtered_acc_x = 0.5 * acc_x_g + 0.5 * filtered_acc_x;
filtered_acc_y = 0.5 * acc_y_g + 0.5 * filtered_acc_y;

// 3. 死区过滤（消除微小抖动）
if (fabs(filtered_acc_x) < 0.05f) filtered_acc_x = 0;
if (fabs(filtered_acc_y) < 0.05f) filtered_acc_y = 0;

// 4. 计算加速度
float ax = filtered_acc_x * sensitivity;
float ay = filtered_acc_y * sensitivity;

// 5. 速度积分（欧拉法）
vx += ax * DT;
vy += ay * DT;

// 6. 应用摩擦力
float friction_coeff = 1.0f - move_speed;
vx *= friction_coeff;
vy *= friction_coeff;

// 7. 限制最大速度
vx = clamp(vx, -MAX_VELOCITY, MAX_VELOCITY);
vy = clamp(vy, -MAX_VELOCITY, MAX_VELOCITY);

// 8. 位置更新
x += vx * DT;
y += vy * DT;

// 9. 边界碰撞检测（弹性系数0.7）
handle_boundary_collision();
```

### 边界碰撞
- **弹性系数**：0.7（保留70%能量）
- **位置修正**：防止小球卡在边界外
- **四边检测**：上下左右四个边界独立处理

### 渲染优化
- **每帧完整重绘**：先清屏再绘制所有元素，避免残影
- **延迟策略**：`os_time_dly(1)` 仅用于让出CPU
- **实际刷新率**：由传感器采样率和系统调度决定（通常30-50 FPS）
- **双缓冲机制**：u8g2的ClearBuffer/SendBuffer确保无闪烁

## 💡 设计要点

### 为什么使用加速度计而不是陀螺仪？

**陀螺仪的问题**：
```c
// ❌ 陀螺仪测量角速度，需要持续改变角度才能移动
// 保持倾斜不动时，角速度=0，小球会停下
vx += gyro_x * sensitivity;  // 不符合直觉
```

**加速度计的优势**：
```c
// ✅ 加速度计测量重力分量，直接反映倾斜角度
// 保持倾斜时，重力分量持续存在，小球持续加速
ax = acc_x_g * sensitivity;  // 符合物理直觉
```

### 为什么显示的是g值而不是m/s²？

**原因**：
- g值更直观：1g = 地球重力加速度
- 数值范围合理：±4g（对应±40 m/s²）
- 便于理解：倾斜30° ≈ 0.5g

**显示示例**：
```
水平放置：X:0.0 Y:0.0
倾斜10°： X:0.0 Y:0.2  (0.17g)
倾斜30°： X:0.0 Y:0.5  (0.50g)
倾斜45°： X:0.0 Y:0.7  (0.71g)
垂直90°： X:0.0 Y:1.0  (1.00g) ← 最大值
```

### 为什么没有花屏？

```c
// 初始化后立即清屏
u8g2_InitDisplay(&u8g2);
u8g2_SetPowerSave(&u8g2, 0);
u8g2_ClearBuffer(&u8g2);  // ← 关键：清除缓冲区
u8g2_SendBuffer(&u8g2);   // ← 关键：发送到屏幕
```

### 为什么没有元素重叠？

- **明确的Y坐标分区**：
  - 标题栏：y=0~13
  - 游戏区：y=14~53
  - 参数栏：y=54~63
- **字体选择合理**：
  - 标题：`u8g2_font_5x7_tr`（高度7像素）
  - 参数：`u8g2_font_5x7_tr`（高度7像素）
- **基线对齐**：所有文字使用基线坐标，不会超出区域

## ⚠️ 注意事项

1. **禁止包含 `<stdio.h>`**：杰理SDK使用自定义printf
2. **禁止使用sprintf**：手动格式化字符串
3. **按键函数必须全局**：`example_key_handler()` 不能是static
4. **每帧必须清屏**：`u8g2_ClearBuffer()` 避免残影
5. **时间步长固定**：使用常量DT，不依赖实际时间差
6. **传感器数据是RAW值**：必须除以8192转换为g值
7. **校准影响数据**：水平放置时Z轴的1g会被减去
