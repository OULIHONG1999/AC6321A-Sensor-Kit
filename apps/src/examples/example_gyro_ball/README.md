# 陀螺仪控制小球示例

## 📖 项目简介

基于陀螺仪传感器实现的小球控制示例，通过倾斜设备控制屏幕上小球的移动，支持按键调整物理参数。

## 🎮 功能特性

### 核心功能
- **陀螺仪控制**：使用X/Y轴角速度控制小球移动
- **物理模拟**：速度、阻尼、边界碰撞等物理效果
- **轨迹显示**：可选显示小球运动轨迹（渐隐效果）
- **参数调节**：实时调整灵敏度、阻尼、小球半径等参数

### 屏幕布局 (128x64)

```
┌─────────────────────────────────┐
│ GYRO BALL CONTROL    [●]        │  <- 标题栏 (y=12)
├─────────────────────────────────┤
│          [小球活动区域]          │  <- 游戏区域 (y=16~54)
│         ●                       │     边界：x=4~124, y=20~52
│        · · ·                    │
│                                 │
─────────────────────────────────┤
│ S:10.0  D:0.5  R:4  T:[ON]      │  <- 参数栏 (y=60)
└─────────────────────────────────┘
```

## 🎯 按键控制

| 按键 | 单击 | 双击 | 长按 |
|------|------|------|------|
| **KEY1** | 灵敏度 +1.0 | 灵敏度 -1.0 | 重置灵敏度 (10.0) |
| **KEY2** | 阻尼 +0.1 | 阻尼 -0.1 | 重置阻尼 (0.5) |
| **KEY3** | 半径 +1 | 半径 -1 | 重置半径 (4) |
| **KEY4** | 轨迹开关 | 清除轨迹 | 重置小球到中心 |

## ⚙️ 参数说明

### 灵敏度 (Sensitivity)
- **范围**：1.0 ~ 50.0
- **默认值**：10.0
- **步进**：±1.0
- **作用**：放大陀螺仪数据，值越大移动越快

### 阻尼系数 (Damping)
- **范围**：0.1 ~ 2.0
- **默认值**：0.5
- **步进**：±0.1
- **作用**：运动阻力，值越大减速越快

### 小球半径 (Radius)
- **范围**：2 ~ 8 像素
- **默认值**：4
- **步进**：±1
- **作用**：小球显示大小

### 轨迹显示 (Trail)
- **状态**：ON / OFF
- **效果**：显示最近50个位置点，透明度渐隐
- **更新间隔**：100ms

## 🔧 物理模型

### 速度更新
```
vx += gyro_x * sensitivity
vy += gyro_y * sensitivity
```

### 阻尼应用
```
vx *= (1.0 - damping)
vy *= (1.0 - damping)
```

### 位置更新
```
ball_x += vx
ball_y += vy
```

### 边界碰撞
- 检测小球是否超出边界
- 反弹并衰减速度（50%）
- 修正位置防止卡住

## 🚀 使用方法

### 启用示例

在 `example_config.h` 中添加：

```c
#define ENABLE_EXAMPLE_GYRO_BALL    1
```

### 初始化

在 `app_main.c` 或相应初始化函数中：

```c
#include "example_gyro_ball/gyro_ball_example.h"

void app_main_init(void)
{
#if ENABLE_EXAMPLE_GYRO_BALL
    gyro_ball_example_start();
#endif
}
```

### 按键事件处理

在 `app_spp_and_le.c` 的按键事件处理中会自动调用 `example_key_handler()`：

```c
// SDK会自动调用 example_key_handler(key_value, event_type)
// 无需手动注册或调用
```

##  显示效果

### 小球渲染
- 使用 `u8g2_DrawDisc()` 绘制实心圆
- 白色填充（绘制颜色1）

### 轨迹渲染
- 最多显示50个轨迹点
- 从新到旧透明度递减
- 使用圆形标记，大小2-3像素

### 参数显示
- 使用 `u8g2_font_5x7_tr` 小字体
- 显示在屏幕底部 (y=60)
- 格式：`S:10.0  D:0.5  R:4  T:[ON]`

## ⚠️ 注意事项

1. **残影避免**：每帧必须调用 `u8g2_ClearBuffer()`
2. **基线坐标**：u8g2的Y坐标是基线，不是顶部
3. **禁止包含stdio.h**：杰理SDK使用自定义printf实现
4. **按键函数必须全局**：供SDK外部调用

## 📝 开发说明

### 传感器数据读取
- 使用QMI8658陀螺仪的X/Y轴角速度
- 单位：弧度/秒 (rad/s)
- 采样频率：建议50-100Hz

### 刷新率
- 显示刷新：50ms (20 FPS)
- 轨迹更新：100ms
- 按键响应：实时
