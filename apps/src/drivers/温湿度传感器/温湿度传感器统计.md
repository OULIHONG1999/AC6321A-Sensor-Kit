## 九、 选型速查

| 场景 | 推荐型号 |
|------|---------|
| 性价比首选（量产） | AHT20 / AHT30 / SHT30 |
| 高精度工业级 | SHT45 / HDC3020 |
| 超小体积 | SHTW2 (1.3mm) / HDC2010 (1.5mm) |
| 超低功耗/电池供电 | SHTC3 / HDC1080 |
| 需要同时测气压 | BME280 / BME680 |
| 入门/学习/原型验证 | DHT22 模块 / BME280 模块 |
| 抗凝露/加热清洗 | HDC3020 / SHT3x（内置加热器） |
